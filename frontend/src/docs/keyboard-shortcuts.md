# Keyboard shortcuts

The site can be driven entirely from the keyboard. Nothing here is
required — every shortcut also has a button — but they make regular use
fast.

## Everywhere

| Shortcut | What it does |
|----------|--------------|
| **Ctrl+K** (Mac: **⌘K**) | Open the help/docs search |
| **/** | Focus the search box on the current page |
| **Esc** | Close any open dialog, menu, or panel |

## Reading a story

| Shortcut | What it does |
|----------|--------------|
| **→** or **Space** | Next chapter |
| **←** | Previous chapter |
| **b** | Save this story to your Library |

## Lists (Discover, Library, forum topics)

| Shortcut | What it does |
|----------|--------------|
| **j** | Move down one item |
| **k** | Move up one item |
| **Enter** | Open the highlighted item |

## In the story editor

| Shortcut | What it does |
|----------|--------------|
| **Ctrl+S** (Mac: **⌘S**) | Save now (it also autosaves on its own) |
| **Ctrl+B** / **Ctrl+I** | Bold / italic on the selection |

## Screen reader and keyboard users

Every interactive element is reachable with **Tab** in a sensible order,
and has a visible focus ring. Dialogs trap focus inside them while open
and return it to the button that opened them when closed.
