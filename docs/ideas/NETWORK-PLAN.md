# The network plan lives in Ascend

`~/code-local/rust/ascend/docs/PLAN-network.md` holds the ordered plan for the things Darkhold and Ascend
build together: the story loop (build → seed → fic → claim), the shared vocabulary and curation engine, the
ranking function, federated trust, one OG renderer and shared taste.

It lives there because Ascend is where the loop starts — a build that cannot become a story is a screenshot.
Darkhold's side of every item is named in that file; nothing here is scheduled separately.
