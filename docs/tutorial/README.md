# Tutorial

Build Lorehaven from an empty directory, one milestone at a time.

Each chapter follows the same shape, so you always know where you are:

1. **Starting checkpoint** — the tag to check out before you begin.
2. **What will work by the end** — the commands you will be able to run.
3. **Concepts introduced** — the ideas the chapter is really teaching.
4. **Commands** — what to type.
5. **Exact file changes** — what appears on disk.
6. **Explanation of important code** — why it is written that way.
7. **Tests** — what is asserted, and what it proves.
8. **Expected UI behaviour** — what you should see.
9. **Troubleshooting** — the failures you are most likely to hit.
10. **Commit / checkpoint** — the tag to leave behind.

Nothing required is left as an exercise for the reader.
