## 5. Environment facts (cost the session real time — read first)

- **Build/test target dir.** The repo lives on the thinkcentre SSHFS mount.
  `cargo test --workspace` with the default `target/` fails mid-run with
  `E0786: invalid metadata files ... Operation not permitted` plus cascading
  `can't find crate` errors. Use:
  `CARGO_TARGET_DIR=~/.cargo-target/lorehaven cargo test --workspace`
  (~40 min first build; incremental after). Plain `cargo check -p <crate>`
  works without it.
- **Suite shape.** `cargo test -p lorehaven-domain --lib` (fast, catches the
  pure-rule regressions) then `cargo test --workspace`. All green at
  `cd87a07` (domain 248, M21 14/14, app suites, zero warnings).
- **Full-suite build time** exceeds the default 180 s tool timeout — run the
  workspace suite with a raised timeout or in the background.
- **`docs/plans/README.md` is stale** (its M-numbering predates the junior
  plan); a banner now says so — do not follow its milestone list.
- **Subagent delegation is broken in this profile** (children die on a model
  routing error); do the work directly.
